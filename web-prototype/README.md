# 噩盡島：新城東境

這是將小說設定轉成遊戲規則的第一個瀏覽器 2D 原型，時間點位於第二部尾聲後的東大陸新城拓荒期。玩家是歲安軍團的一般巡防員，不取代小說既有角色。

## 目前流程

1. 在軍團報到時測定發散或內聚傾向。
2. 從息壤城區出發，進入道息較高的東門緩衝帶。
3. 使用爆、輕、柔、凝四訣對付鑿齒，取得妖物遺骸。
4. 回到新城煉化臺，將遺骸煉成妖質。
5. 在聚炁鏡附近完成首次易質，承受低道息衰弱。
6. 返回荒原，阻止刑天統領逼近新城。

道息是區域環境值，會影響炁息恢復與妖物強度；炁息則是玩家施展炁訣和身法時實際消耗的資源。

## 操作

- `WASD` 或方向鍵：移動
- `J` 或空白鍵：施展目前炁訣
- `K`：身法；輕訣的距離較遠、消耗較低
- `1` 至 `4`：切換爆、輕、柔、凝
- `Q`、`E`：循環切換炁訣
- `F`：在煉化臺互動

手機與窄螢幕會自動顯示觸控按鍵。

## 啟動

```bash
npm install
npm run dev
```

生產建置與端對端驗證：

```bash
npm run build
npm run test:e2e
```

遊戲進度保存在瀏覽器的 `localStorage`。
