# 噩盡島 Minecraft 角色扮演插件

以 Paper 1.20.4 製作的非官方、非商業生存 RPG 插件。遊戲時間點設在第二部尾聲後，玩家從東大陸新城展開自己的巡防與拓荒歷程，不取代原作既有人物。

> 本專案是由愛好者獨立製作的非官方二次創作，未獲原作者、出版社、Mojang 或 Microsoft 授權、認可或贊助。原作及 Minecraft 的相關權利均歸各自權利人所有。

目前版本為 `0.9.0`，定位仍是可遊玩的核心系統原型。世界生成、角色定型、兵器、首批妖族 AI、單人 NPC 支援與雙人巡防流程已可運作；能持續一個月以上的勢力、建設與長期事件系統尚未完成。

## 支援環境

- Minecraft Paper `1.20.4`
- Java `17` 以上
- macOS 或 Linux 建置環境；Windows 可透過 WSL 執行建置腳本

## 已完成內容

- 自動建立 2 倍尺度主世界 `evil_island_hd`，不覆蓋原版 `world`
- 建立新城、歲安城、九回山、山口鎮、絨須洞、魔法島與龍宮等主要區域
- 以場景互動完成角色測定、炁訣定型、領取兵器、巡防、煉化與易質
- 永久保存發散／內聚傾向與炁訣路線，玩家不能任意重配
- 六種制式兵器及各自的主動招式
- 鑿齒與刑天的自訂戰鬥狀態機
- 不需指令的單人／雙人巡防編組、動態難度與共享獎勵
- 單人巡防的揚武 NPC 跟隨、戰鬥、倒地及救援行為
- 可跨重啟恢復隊員、階段與離線獎勵的巡防錨點
- 主世界與龍宮內層領域間的互動式界門
- 玩家進度、妖質與角色資料保存於 Persistent Data Container

地標、座標及目前重建範圍見 [WORLD_ATLAS.md](WORLD_ATLAS.md)，玩法系統基線見 [PLUGIN_ARCHITECTURE.md](PLUGIN_ARCHITECTURE.md)，完整版本順序與驗收條件見 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)。

## 玩家流程

1. 第一次加入後抵達東大陸新城。
2. 前往聚炁鏡庭接受先天傾向測定。
3. 再次與聚炁鏡互動，選擇四種純訣或相鄰雙修路線；確認後永久定型。
4. 前往東門與撼山巡防員互動，從軍械庫選擇一件登記兵器。
5. 再次與巡防員互動，選擇單人或與附近一名玩家雙人編組。
6. 進入城外高道息區，擊退鑿齒並讓每名隊員取得妖物遺骸。
7. 回到煉化工坊，將遺骸煉成妖質。
8. 全隊完成第一次易質後，迎戰依隊伍人數調整強度的刑天統領。

兵器右鍵會施展該武器招式，潛行加右鍵則會運用已定型的炁訣。炁息是施展能力的消耗值；區域道息會影響炁息恢復、易質者在息壤區的衰弱及妖族強度。

玩家死亡會失去尚未煉化的隨身遺骸，已煉化妖質與角色進度則會保留。

## 兵器與炁訣

六種制式兵器包括長槍、雙鐧、戰刀、長劍、雙匕與刀盾，分別偏向突進、承傷、重擊、反擊、位移及固守。兵器可以更換，不會改變已定型的炁訣。

四種基礎炁訣為：

- `爆訣`：外放、震擊與較高近戰傷害
- `輕訣`：移動、身法與衝刺攻擊
- `柔訣`：卸勁、減傷、反震與推離
- `凝訣`：吸收、護體與限制敵人行動

普通原版武器仍能造成物理傷害，但不會觸發炁訣與登記兵器效果。

## 妖族戰鬥行為

鑿齒目前使用豬布獸作為暫時模型。小隊會固定分成正面與左右側翼，互相提供群戰強化；中距離跳擊會先以粒子與音效預警，玩家可移動閃避。低血量時鑿齒會加快移動，但不會離開遭遇區無限追擊。

刑天目前使用衛道士作為暫時模型。它會顯示首領生命條、指揮附近鑿齒集中攻擊並提供強化；近距離震擊有蓄力範圍提示，中距離則會預警後衝鋒。生命低於設定比例後會進入震怒階段，提升防禦、移動速度及技能頻率。

妖族只會主動鎖定該次編組中已完成報到、處於生存模式的玩家，以及仍能戰鬥的編組 NPC。玩家離開後，妖族會返回出生區並逐步恢復；區塊重新載入或伺服器重啟後，也會依實體上的持久資料恢復 AI 追蹤。

## 單人與雙人巡防

玩家持有登記兵器後，右鍵新城東門的撼山巡防員即可開啟編組介面。單人模式會由一名揚武巡防員使用弩提供遠程支援；它會跟隨玩家、尋找同一遭遇中的敵軍，生命耗盡時先進入倒地狀態。玩家靠近並右鍵可以立即救援，逾時後 NPC 也會以較低生命自行恢復。

雙人模式會邀請巡防員附近、角色進度相同且已持有兵器的最近玩家，對方需在編組介面確認。雙人不額外生成 NPC，而是增加鑿齒數量，並提高鑿齒與刑天的生命及傷害。所有隊員共享擊殺進度，每名隊員都會各自取得遺骸；暫時離線者的遺骸與結算會保存在遭遇錨點，重新加入後補發。

巡防期間再次右鍵撼山巡防員可以查看編組、階段與剩餘敵軍，也能經過確認後終止卡住的任務。正式流程不需要輸入隊伍或任務指令。

## 建置與安裝

本專案是遊戲內容插件，通用領域規則由[持久型角色扮演引擎](https://github.com/mlgzackfly/persistent-rpg-engine)公開專案提供，目前相容版本為 `v0.1.0`。本機預設目錄結構如下：

```text
minecraft/
├── persistent-rpg-engine/
└── evil-island-plugin/
```

建置腳本會先建置公開引擎，再自動下載 Paper API 及必要編譯依賴；依賴與輸出皆不納入 Git。若引擎位於其他位置，可設定 `RPG_ENGINE_DIR`：

```bash
./build.sh
# RPG_ENGINE_DIR=/path/to/persistent-rpg-engine ./build.sh
```

測試通過後會產生 `build/EvilIsland.jar`。將它放入 Paper 1.20.4 伺服器的 `plugins/` 目錄，再啟動伺服器即可。第一次載入會自動建立插件世界；大型地標會分批生成，避免長時間阻塞伺服器主執行緒。

## 瀏覽器原型

`web-prototype/` 是獨立的 2D 玩法驗證工具，不是 Minecraft 世界存檔或正式客戶端：

```bash
cd web-prototype
npm ci
npm run dev
```

生產建置使用 `npm run build`。端對端測試需先執行 `npm run preview`，再於另一個終端執行 `npm run test:e2e`。

Dynmap 可用於瀏覽實際 Paper 世界，但它的插件、圖磚與伺服器設定屬於本機執行資料，不包含在此儲存庫。

## 指令

正式玩家流程不依賴指令。玩家可使用：

- `/evil status`：查看角色、炁息、道息、妖質與任務狀態
- `/evil guide`：查看目前目標

`/evil admin` 下的 `atlas`、`setup`、`spawn`、`reset`、`reload` 與 `selftest` 僅供建圖、驗證及除錯使用，需要 `evilisland.admin` 權限。舊版 `/eji` 仍保留為相容別名。
