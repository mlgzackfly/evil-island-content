# 噩盡島 Minecraft 角色扮演插件

以 Paper 1.20.4 製作的非官方、非商業生存 RPG 插件。遊戲時間點設在第二部尾聲後，玩家從東大陸新城展開自己的巡防與拓荒歷程，不取代原作既有人物。

> 本專案是由愛好者獨立製作的非官方二次創作，未獲原作者、出版社、Mojang 或 Microsoft 授權、認可或贊助。原作及 Minecraft 的相關權利均歸各自權利人所有。

目前開發版本為 `0.12.2-dev`，定位仍是可遊玩的核心系統原型。世界生成、角色定型、兵器、八種妖族職責、單人 NPC 支援、雙人編組、SQLite 持久化、七類任務、三條城市路線、安全實體工程、四條異族交涉、有限互助庫存、地標探索、連續事件與跨輪結算已可運作；另提供可回復的管理驗收預覽。完整故事場景、專用模型及真人長期平衡仍待後續版本完成。

## 支援環境

- Minecraft Paper `1.20.4`
- Java `17` 以上
- macOS 或 Linux 建置環境；Windows 可透過 WSL 執行建置腳本

- 非戰鬥任務不直接提供妖質或永久戰力，重複戰鬥材料收益會遞減

- 自動驗證三條路線、五項三級工程與四族使者，保存方塊快照並產生繁體中文報告
- 輪次結局「遠路重開、諸族互市、新城固守、艱難續存」與工程、關係、探索繼承
- 主世界與龍宮內層領域間的互動式界門
- 玩家進度、妖質與城況保存於 SQLite；PDC 只保存物品及實體識別

## 玩家流程

1. 第一次加入後抵達東大陸新城。
2. 前往聚炁鏡庭接受先天傾向測定。
3. 再次與聚炁鏡互動，選擇四種純訣或相鄰雙修路線；確認後永久定型。
4. 前往東門與撼山巡防員互動，從軍械庫選擇一件登記兵器。
5. 從輕疾巡防公告的三份契約中擇一，再選擇單人或與附近一名玩家雙人編組。
6. 進入城外高道息區，依契約風險擊退不同規模與強度的鑿齒。
7. 回到煉化工坊，將遺骸煉成妖質；首次遊玩需在聚炁鏡旁完成第一次易質。
8. 迎戰依契約、城況與隊伍人數調整強度的刑天統領。
9. 完成第一次易質後，每日公告會提供巡防與兩種輪替外勤，包含採集、偵察、護送、救援或守城。
10. 由公告召開本週部署會議，在加固防線、維持補給與先制偵察中確認一項全服方針。
11. 每日首次完成會提升對應城況；隔日公告、城況消耗與任務組合會更新。
12. 每輪前三日從發展總覽二次確認固城、遠征或聚炁民生路線；本輪選定後不可改選。
13. 將任務所得投入城牆、聚炁鏡陣、軍械工坊、輕疾站或防空弩臺；安全地塊會逐階出現實體工程。
14. 完成當週異族使者要求的兩種任務，再選擇合作、保持距離，或在犬戎事件中承擔衝突後果。
15. 依探索情報前往東境補給路、宇定高原東壁、絨須洞外緣、西方荒野或龍宮海岸；接觸當地族群、危險路線與特殊素材。
16. 完成當週連續事件，或使用公共物資採取非戰鬥方案；四週後依工程、關係、事件與探索成果結算並進入下一輪。

兵器右鍵會施展該武器招式，潛行加右鍵則會運用已定型的炁訣。炁息是施展能力的消耗值；區域道息會影響炁息恢復、易質者在息壤區的衰弱及妖族強度。

玩家死亡會失去尚未煉化的隨身遺骸，已煉化妖質與角色進度則會保留。從 `0.10.0` 開始，角色資料保存於 SQLite；舊版 PDC 資料會在玩家首次加入時自動匯入，成功寫入後才清除舊欄位。

## 兵器與炁訣

六種制式兵器包括長槍、雙鐧、戰刀、長劍、雙匕與刀盾，分別偏向突進、承傷、重擊、反擊、位移及固守。完成任務會累積目前登記兵器的熟練；軍械工坊達到第一階段後，可選擇疾行、制敵或守勢運用。熟練階段只提高位移、控制或防守效果，不會改變已定型的炁訣，也不直接堆疊永久傷害。正式兵器更換與維護尚未開放。

四種基礎炁訣為：

- `爆訣`：外放、震擊與較高近戰傷害
- `輕訣`：移動、身法與衝刺攻擊
- `柔訣`：卸勁、減傷、反震與推離
- `凝訣`：吸收、護體與限制敵人行動

普通原版武器仍能造成物理傷害，但不會觸發炁訣與登記兵器效果。

## 妖族戰鬥行為

鑿齒目前使用豬布獸作為暫時模型。小隊會固定分成正面與左右側翼，互相提供群戰強化；中距離跳擊會先以粒子與音效預警，玩家可移動閃避。低血量時鑿齒會加快移動，但不會離開遭遇區無限追擊。

刑天目前使用衛道士作為暫時模型。它會顯示首領生命條、指揮附近鑿齒集中攻擊並提供強化；近距離震擊有蓄力範圍提示，中距離則會預警後衝鋒。生命低於設定比例後會進入震怒階段，提升防禦、移動速度及技能頻率。

犬戎獵手會保持狩獵距離、牽制目標並在負傷時撤回領域，領獵則會強化附近獵手。禺彊掠空者從空中施加衰弱與拋升，破風者的壓制頻率更高；防空弩臺能減少海岸調查時的掠空數量。毛族使者與納金族商旅不是敵怪，互動後會開啟交涉介面。犬戎或虯龍關係達到互利時，部分探索遭遇可直接安全通行。

妖族只會主動鎖定該次編組中已完成報到、處於生存模式的玩家，以及仍能戰鬥的編組 NPC。玩家離開後，妖族會返回出生區並逐步恢復；區塊重新載入或伺服器重啟後，也會依實體上的持久資料恢復 AI 追蹤。

## 單人與雙人任務

玩家持有登記兵器後，右鍵新城東門的撼山巡防員即可開啟編組介面。單人巡防與護送由揚武使用弩提供遠程支援；單人偵察與救援由無跡斥候追蹤地面足跡。揚武生命耗盡時會倒地，可由玩家右鍵立即救援；事後會留下負傷與疲勞。

雙人模式會邀請巡防員附近、角色進度相同且已持有兵器的最近玩家，對方需在編組介面確認。雙人不額外生成 NPC，而是增加鑿齒數量，並提高鑿齒與刑天的生命及傷害。所有隊員共享擊殺進度，每名隊員都會各自取得遺骸；暫時離線者的遺骸與結算會保存在遭遇錨點，重新加入後補發。

巡防期間再次右鍵撼山巡防員可以查看編組、階段與剩餘敵軍，也能經過確認後終止卡住的任務。正式流程不需要輸入隊伍或任務指令。

採集任務會要求全隊共同準備指定原版物資，雙人需求為單人的 `1.5` 倍，繳交時由在線隊員背包共同扣除。偵察任務會在高道息荒原生成發光觀測標，任一隊員右鍵啟動即可完成。護送需帶路線 NPC 離城並清除中途伏擊；救援需先找到倒地巡防員，右鍵救起、擊退追兵，再帶回新城巡防站。

守城任務會在東門巡防站周邊從兩至四個方向發動兩至三波攻勢。鑿齒接近工事時會被阻滯並破壞耐久；隊員可右鍵工事消耗一份鵝卵石修復。總共三名敵軍突破中心時任務失敗，城防與民心會立即下降。

公告介面的「巡防員狀態與治療」可查看揚武、無跡的疲勞與負傷。消耗一瓶蜂蜜可解除負傷並降低疲勞；若 NPC 不能出勤，主要任務仍可單人完成，戰鬥難度會自動下修。

## 四週城況與每日契約

撼山巡防員會透過輕疾公告顯示當日三份不同類型契約。三十七種契約包含十二種巡防及採集、偵察、護送、救援、守城各五種，分別影響城防、供應、情報或民心。公告每日固定保留一份巡防，其他兩席由五種外勤輪替。

每日只有第一次完成契約會提升城況並發放完整額外報酬。非戰鬥任務只恢復少量炁息；重複戰鬥保留刑天遺骸，但不再由每隻鑿齒無限產出材料。尚未完成第一次易質的新玩家固定取得完整教學收益。未完成一日出勤時，城防、供應、情報與民心會受到不同程度的消耗。

日程依序經過「開拓整備、補給吃緊、敵軍集結、決戰警戒」四個階段；每七日進入下一週、四週進入下一輪。公告中的每週事件需在週末前完成二次確認；未處理時會依當週問題額外扣除城況。加固、補給與偵察的累積結果會在第四週生成「破陣刑天」、「劫糧刑天」或「負創刑天」，分別改變首領生命、傷害與護衛數量。

## 城市、探索與跨輪發展

每日首次完成任務會依類型帶回建材木料、築城石材、城防糧秣、息壤構件或異族素材；公共庫存由全服共享，同日重複出勤不會無限產生工程資源。每輪前三日可選定固城、遠征或聚炁民生路線，指定工程成本降低兩成，並分別減少守城敵軍、增加探索所得，或提高城內炁息恢復。路線每輪互斥，下一輪才可重選。

五項工程各有三個階段，成本設計使單輪無法全部完成。新城外牆提高工事耐久，聚炁鏡陣改善城內炁息恢復，軍械工坊開放橫向技法，輕疾站增加探索收穫，防空弩臺壓制禺彊增援。實體施工會先掃描 9×9 地塊的高度、道路材質、既有建築與淨空；不合格時只保留展示標記。插件會保存每個施工方塊的原始與放置資料，外部改動造成衝突時暫停後續施工，不強制覆蓋。

探索頁會提供五處調查點的實際座標；第一次抵達現場後自動完成調查，不必輸入指令。輕疾站達到第二階段後，已發現地點可消耗一份糧秣快速部署。不同地區可能出現非敵對使者、犬戎巡獵或禺彊空襲；與犬戎交戰會降低關係，投入糧秣交涉則能逐步取得安全通行。每週另有一條三階段連續事件，指定的偵察、護送、採集、救援、巡防或守城結果會推進事件；玩家也可消耗對應公共物資採取非戰鬥方案。安全線會增加後續補給，流民事件與敵軍集結則會共同改變第三週守城每個入口的敵軍壓力；集結情報也會增減第四週刑天護衛。

每週會依週次與城市路線出現犬戎、毛族、納金族或虯龍使者。完成契約指定的兩種任務後，可消耗對應公共物資合作、保持距離，或在犬戎事件中驅離獵隊。合作只開放當週有限庫存；每名玩家也必須靠對應任務取得個人額度，因此不能由單一玩家清空供應，也沒有可無限累積的通用貨幣。

四週結算會記錄工程總階段、完成事件及本輪探索，產生一種輪次結果。工程完整保留，勢力關係小幅回落，未使用物資最多保留一半且有上限，探索點可在下一輪重新調查，事件鏈與城市路線則重新開始。離線跨過多輪時也會逐輪產生紀錄，不會只跳過中間狀態。

## 建置與安裝

本專案是遊戲內容插件，通用領域規則由[持久型角色扮演引擎](https://github.com/mlgzackfly/persistent-rpg-engine)公開專案提供，目前相容版本為 `v0.1.0`。本機預設目錄結構如下：

```text
minecraft/
├── persistent-rpg-engine/
└── evil-island-plugin/
```

建置腳本會先建置公開引擎，再自動下載 Paper API 及必要編譯依賴；依賴與輸出皆不納入 Git。若引擎位於其他位置，可設定 `RPG_ENGINE_DIR`：

```bash
./build.sh
# RPG_ENGINE_DIR=/path/to/persistent-rpg-engine ./build.sh
```

測試通過後會產生 `build/EvilIsland.jar`。將它放入 Paper 1.20.4 伺服器的 `plugins/` 目錄，再啟動伺服器即可。第一次載入會自動建立插件世界；大型地標會分批生成，避免長時間阻塞伺服器主執行緒。

正式資料庫位於 `plugins/EvilIsland/evilisland.sqlite3`。每次啟動會先完成 WAL checkpoint，再將既有資料庫備份到 `plugins/EvilIsland/backups/`；保留數量與自動保存週期可由 `config.yml` 調整。這些執行資料不納入 Git。

## 瀏覽器原型

`web-prototype/` 是獨立的 2D 玩法驗證工具，不是 Minecraft 世界存檔或正式客戶端：

```bash
cd web-prototype
npm ci
npm run dev
```

生產建置使用 `npm run build`。端對端測試需先執行 `npm run preview`，再於另一個終端執行 `npm run test:e2e`。

Dynmap 可用於瀏覽實際 Paper 世界，但它的插件、圖磚與伺服器設定屬於本機執行資料，不包含在此儲存庫。

## 指令

正式玩家流程不依賴指令。玩家可使用：

- `/evil status`：查看角色、炁息、道息、妖質與任務狀態
- `/evil guide`：查看目前目標

`/evil admin` 下的 `acceptance`、`atlas`、`setup`、`spawn`、`reset`、`reload` 與 `selftest` 僅供建圖、驗證及除錯使用，需要 `evilisland.admin` 權限。指令前綴統一使用 `/evil`，另保留完整名稱 `/evilisland` 作為別名。

### 無客戶端自動驗收

管理員可從 Paper console 執行：

```text
evil admin acceptance run
evil admin acceptance status
evil admin acceptance restore
```

`run` 不修改正式角色、輪次、路線、公共物資、工程等級或契約進度。它會使用正式安全選址與藍圖規則，在新城周邊暫時建立五項階段 3 工程，生成犬戎、毛族、納金族與虯龍四名驗收使者，並檢查三條路線的工程折扣、每週契約、守城、部署及聚炁差異。所有預覽方塊都會先將原始與放置資料寫入 schema v7，再分批施工。

完成後可依 console 顯示的 Dynmap 網址與工程座標從瀏覽器檢查。繁體中文報告位於 `plugins/EvilIsland/acceptance/latest-report.md`。`restore` 會按快照復原；預設十分鐘逾時、正常停服或預覽期間重啟也會自動復原。若方塊已被外部修改，工具不會強制覆蓋，而會將位置列為復原衝突。資料庫預設只保留最近五次驗收與方塊快照，可透過 `acceptance.retained-runs` 調整；Dynmap 圖層則由 `acceptance.dynmap-map` 指定。
